# wake-up-up 要件定義書(MVP)

## 1. 目的
毎日の起床時刻を記録し、目標時刻より早く起きられた日にアプリ内ポイントを獲得できるようにして、早起きの習慣化を支援する。

## 2. 前提
- 利用者: 自分一人(アカウント・ログイン・サーバー不要)
- 技術: Flutter(モバイル)
- 起床記録: 手動で「起きた」ボタンを押す
- 報酬: アプリ内ポイント
- 目標時刻: 全日共通の固定時刻(曜日別設定はしない)

## 3. 機能要件

### 3.1 目標起床時刻の設定
- 1つの時刻(例 6:30)を設定・変更できる。
- 変更は当日以降の判定に適用する(過去の記録は変更しない)。

### 3.2 起床記録
- ホーム画面の「起きた」ボタンを押すと、現在日時を起床時刻として保存する。
- 1日1回のみ記録できる(押下済みの日は再度押せない)。
- 記録時点の目標時刻も一緒に保存する(後から目標を変えても過去の判定が変わらないようにするため)。

### 3.3 判定とポイント付与
- 起床時刻 ≦ 目標時刻 → 成功。ポイントを付与する。
- 起床時刻 > 目標時刻 → 失敗。ポイントなし。
- ポイントルール(確定):
  - 成功: 10pt
  - 目標より10分早いごとに +1pt(上限 +5pt)
  - 連続成功ボーナスは MVP では見送り

### 3.4 履歴・確認
- ホーム画面に、今日の状態(未記録/成功/失敗)、累計ポイント、連続成功日数を表示する。
- 履歴画面で、日ごとの起床時刻・目標時刻・成否・獲得ポイントを一覧できる(カレンダー表示は後回し可)。

### 3.5 「日」の区切り
- 午前0時ではなく、午前3:00を日付の境界とする(確定)。深夜の記録が前日扱いになるようにするため。

## 4. 非機能要件
- データは端末内にローカル保存する(オフラインで動作)。
- 起動してから「起きた」を押すまで2タップ以内。
- 対象OS: iOS / Android 両方(Flutter で共通実装)。

## 5. スコープ外(MVP では作らない)
- アラーム機能(普段使っているアラームアプリを使う)
- ポイントの使い道(交換・ご褒美機能)
- 通知、ウィジェット、クラウド同期、複数端末対応
- 不正防止(二度寝対策、ボタンを先に押す行為への対策)

## 6. 想定技術構成(案)
- Flutter + Dart
- 状態管理: Riverpod
- ローカル保存: SQLite(drift)または shared_preferences
- テスト: 判定・ポイント計算を純粋関数にして単体テストする

## 7. 決定事項
1. 目標時刻は全日固定
2. ポイントルールは 3.3 の案を採用
3. 日付境界は午前3:00
4. 対象OSは iOS / Android 両方
5. 記録の後追い追加・修正機能は作らない

未決事項はなし。
